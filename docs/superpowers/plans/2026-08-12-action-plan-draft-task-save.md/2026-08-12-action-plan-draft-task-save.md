# 조치계획 임시 과제 저장 Implementation Plan

**Goal:** 마지막 임시 과제 입력 행이 신규 과제 추가 버튼 없이도 조치계획 저장 요청에 포함되게 한다.

**Architecture:** `ActionPlan`은 저장 콜백에 임시 과제 입력값을 전달한다. 상위 컴포넌트는 제목이 비어 있지 않을 때만 이를 기존 `tasks`와 합쳐 API 페이로드로 변환한다.

## 검증

- 임시 과제명, 담당자, `null` 마감일이 저장 페이로드에 포함된다.
- 빈 임시 과제명은 저장 요청에서 제외된다.
- 전체 테스트와 빌드를 실행한다.
