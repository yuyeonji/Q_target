# Q-Target 인터랙티브 데모 보강 설계

## 목표

기존 화면 재현 데모를, 주요 조작이 눈에 보이는 결과로 이어지는 발표·검토용 인터랙티브 데모로 완성한다.

## 포함 기능

- 알람 목록: 검색어, 상태 필터(전체·신규·검토중·종결), 필터 초기화, CSV 다운로드를 제공한다.
- 관리대상 목록: 제목 검색과 상태 필터를 제공하고, 행별 조치계획 진입을 유지한다.
- 신규 케이스: 제목과 우선순위를 입력해 관리대상 목록에 즉시 새 행을 추가한다.
- 마스터 관리: 탭별 규칙 목록을 표시하고, 규칙 추가·활성/비활성 토글·임계값 편집을 반영한다.
- 알람 상세의 종결·모니터링 버튼과 조치계획 저장은 알람/관리대상 상태를 화면 내 데이터로 갱신하고 성공 안내를 표시한다.

## 데이터와 상태

모든 데이터는 React 상태로 관리하며 새로고침 시 초기값으로 되돌린다. 목록 데이터는 객체 배열로 통일하고, 검색과 필터는 동일한 배열에 적용한다. CSV는 현재 필터링된 알람 목록만 브라우저 다운로드로 생성한다.

## 사용자 흐름

1. 사용자가 알람을 검색·필터링하고 행을 선택한다.
2. 상세에서 종결, 모니터링 유지, 관리대상 등록 중 하나를 선택하면 목록과 안내가 갱신된다.
3. 신규 케이스 또는 조치계획 저장은 관리대상 목록의 상태를 즉시 바꾼다.
4. 마스터 관리에서 규칙을 새로 만들거나 상태·임계값을 조정한다.

## 오류 처리와 검증

- 제목 없는 신규 케이스와 규칙은 입력 안내를 표시하고 생성하지 않는다.
- 검색·필터 결과가 없으면 빈 상태를 표시한다.
- CSV 다운로드는 행이 하나 이상일 때만 가능하며, 없으면 안내를 표시한다.
- 서버 렌더링 테스트에 데모 기본 화면과 상호작용용 텍스트가 포함되는지 검증하고, 브라우저에서 필터·생성·다운로드 흐름을 점검한다.

## 제외 범위

서버 API, 로그인, 영구 저장, 실제 파일 업로드, 실제 알림 발송과 설비 데이터 연동은 포함하지 않는다.
