# 조치계획 새로고침 복원 설계

## 목표

관리대상 목록에서 조치계획을 열 때, 저장된 조치계획과 과제를 먼저 불러온 뒤 팝업을 표시한다. 새로고침 뒤에도 같은 관리대상을 열면 마지막으로 저장한 조치계획이 즉시 나타나야 한다.

## 동작

1. 사용자가 관리대상의 조치계획을 연다.
2. 화면은 해당 관리대상의 최신 조치계획을 API에서 가져온다.
3. 요청이 성공하면 저장된 계획을 초기값으로 사용해 팝업을 연다. 저장된 계획이 없으면 빈 새 계획 팝업을 연다.
4. 요청이 실패하면 팝업을 열지 않고 오류 안내를 표시한다.

## 구현 범위

- `openTargetActionPlan`에서 팝업 표시를 데이터 조회가 끝난 뒤로 이동한다.
- 저장된 계획과 과제의 상태를 조회 결과로 초기화한다.
- 기존 저장 및 수정 API와 데이터베이스 구조는 변경하지 않는다.

## 검증

- 저장된 조치계획이 있는 관리대상을 열면 API의 조치 내용과 과제가 팝업에 표시되는지 테스트한다.
- 조회 중 기본 예시 문구가 입력값으로 표시되지 않는지 테스트한다.
- 전체 기존 테스트와 빌드를 실행한다.
