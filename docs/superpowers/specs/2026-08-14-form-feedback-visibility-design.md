# 저장·종결 피드백 가시성 설계

## 목표

저장 또는 종결을 시도한 뒤에만 누락된 입력값과 처리 결과를 눈에 띄고 일관된 방식으로 표시한다. 기존의 팝업 하단 단일 문구는 제거한다.

## 표시 원칙

- 사용자가 저장·종결 버튼을 누르기 전에는 필수값 오류를 표시하지 않는다.
- 누락된 값은 해당 입력칸 바로 아래에 빨간 안내 문구와 오류 테두리로 표시한다.
- 한 번에 여러 항목이 누락된 경우, 팝업 상단 고정 영역에 누락 항목 수와 목록을 요약한다.
- 성공은 기존 토스트를 유지하되 성공 색상으로 표시한다.
- 저장 실패나 DB 연결 실패는 닫을 수 있는 빨간 오류 배너로 표시하고, 입력값은 유지한다.

## 적용 범위

- 조치계획 저장과 종결 처리: 분석·조치 입력, 과제, 완료 조건, 종결 사유.
- 관리대상 등록, 신규 관리대상, 마스터 코드·규칙 생성/수정: 빈 필수 입력값.
- 알람 상태 변경과 서버 저장 실패: 결과 배너/토스트.

## 상호작용

1. 사용자가 저장 또는 종결 버튼을 누른다.
2. 클라이언트 유효성 검사가 실패하면 페이지 이동 없이 해당 필드와 상단 요약만 표시한다.
3. 사용자가 오류 필드를 보완하면 해당 필드 안내와 요약 항목이 즉시 사라진다.
4. 서버 요청이 실패하면 폼은 열린 채로 유지하고 오류 배너를 표시한다.
5. 저장 성공 후에는 성공 토스트를 표시하고 기존 새로고침 흐름을 유지한다.

## 검증

- 저장 전에는 오류 안내가 렌더링되지 않는다.
- 저장/종결 시 누락 필드가 모두 표시된다.
- 필드를 보완하면 해당 오류가 해제된다.
- 서버 저장 실패 시 입력값과 팝업이 유지된다.
